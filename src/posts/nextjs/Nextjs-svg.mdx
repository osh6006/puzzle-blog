Next.js로 다양한 팀 프로젝트를 진행하면서 SVG를 다루는 방식이 조금씩 달랐습니다. 이러한 방법들을 한곳에 정리해, 나중에 팀원들과 가장 적합한 방법을 논의해보면 좋겠다는 생각이 들었습니다.

따라서 오늘은 제가 여러 블로그와 문서를 참고하며 사용했던 Next.js에서 SVG를 처리하는 다양한 방법을 정리해보려고 합니다. 이 글이 프로젝트에서 SVG를 다룰 때 도움이 되기를 바랍니다.

### 공식 문서에서는 어떻게 사용할까??

공식 문서에서는 아래의 코드처럼 Next.js에서 제공하는 `<Image/>`에 public폴더 경로에 있는 SVG 파일의 경로를 입력하여 사용할 수 있도록 권장하고 있습니다.

```ts
import Image from "next/image";
import SVGIMG from "/vercel.svg";

export default function Page() {
    return (
       <Image src={SVGIMG} alt={"something SVG!!"}/>
    )
}
```

이렇게 코드를 사용하게 되면 Next.js가 권장하는 방식으로 svg를 사용할 수 있고 Next.js에서 제공하는 최적화 방식을 사용할 수 있기에 간단하게 사용하기에 좋았습니다.

**하지만 저는 Lucid Icons 라이브러리 처럼 내 맘대로 SVG의 색과 사이즈를 조절할 수 있는 컴포넌트** 를 만들고 싶었습니다. Next.js에서 제공하는 `<Image/>` 태그로는 더 세밀한 조정이 어려워 다른 방법을 찾아야 했습니다.

### Svgr 사용하기

이것을 해결하기 위한 첫 번째 방법으로 Svgr 라이브러리를 사용해 보았습니다. Svgr 라이브러리는 svg 이미지를 react나 nextjs에서 쉽게 다루기 위해서 만들어진 webpack 설정으로, svg 파일을 컴포넌트로 자동으로 변환시켜 사용할 수 있게 해 줍니다.

React, Next, Remix등 다양한 환경에서 사용할 수 있도록 [공식 문서](https://react-svgr.com/docs/next/)도 아주 친절하게 설명 되어 있어서 매우 쉽게 프로젝트에 적용할 수 있었습니다. 

#### 사용방법

<Callout type="warn" row={true}>
  현 시점 방법이 바뀌었을 수 있습니다. 꼭 공식 문서를 확인하시길 바랍니다.
</Callout>

우선 터미널에서 필요한 라이브러리를 다운받아 줍니다.

```bash
npm install --save-dev @svgr/webpack
# or use yarn
yarn add --dev @svgr/webpack
```

그리고 `nextjs.config.js` 파일에 아래의 코드 처럼 svgr 설정을 해 줍니다.

```js
/** @type {import('next').NextConfig} */
const nextConfig = {
  webpack: (config) => {
    config.module.rules.push({
      test: /\.svg$/,
      use: ['@svgr/webpack'],
    });

    return config;
  },
};

export default nextConfig;

```

그리고 사용할 때 아래의 코드 처럼 경로를 불러와 컴포넌트 처럼 사용하면 됩니다.

```tsx
import Star from './star.svg'

const Example = () => (
  <div>
    <Star />
  </div>
)
```

하지만 저는 이렇게 사용하는 방법도 좋지만 **`<Icon/>` 이라는 공통 컴포넌트를 만들어 name, color, size 라는 props를 받고 프로젝트 전체에서 쓸 수 있는 컴포넌트를 만들고 싶었습니다.**

따라서 아래처럼 `types/icon.ts` 경로의 파일에 svg 컴포넌트를 넣어주고 (name props와 아이콘 컴포넌트에 쓰기 위해),

```ts
// types/icon.ts
export { default as Back } from '../../public/icons/back.svg';
export { default as Category } from '../../public/icons/category.svg';
export { default as Home } from '../../public/icons/home.svg';
```

공통 컴포넌트인 `Icon` 컴포넌트에서는 아래와 같이 코드를 작성해 주었습니다.

```tsx
import React from 'react';

import * as icons from '@/types/icons';

interface IIconProps {
  name: keyof typeof icons;
  size?: number;
  color?: string;
  className?: string;
}

const Icon: React.FC<IIconProps> = ({
  name,
  size = 24,
  color = 'black',
  className,
}) => {
  const SvgIcon = icons[name];
  if (!SvgIcon) {
    console.warn(`Icon ${name} does not exist.`);
    return null;
  }


  return (
    <SvgIcon
      width={size}
      height={size}
      color={color}
      className={className}
    />
  );
};

export default Icon;
```

해당 컴포넌트를 사용하려면 아래와 같이 사용하면 됩니다!

```tsx
<Icon
name="Back"
size={16}
color="#F8BE27"
/>
```

위와 같이 사용한 결과 더 쉽게 간단한 코드로 SVG파일을 다룰 수 있었기 때문에 매우 편리하게 사용할 수 있었습니다. 하지만 **라이브러리를 사용하지 않고 공통 컴포넌트를 만들 수 없을까?** 하는 의문이 들어 한 가지 방법을 더 찾게 되었습니다.
