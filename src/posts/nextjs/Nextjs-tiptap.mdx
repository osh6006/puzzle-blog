새로운 프로젝트를 구현하면서 새로운 글을 등록하거나 기존 글을 불러오는 작업에서 **에디터가** 필수적이었습니다. 지금까지는 **React Quill**이나 **React Draft** 같은 에디터들을 사용했지만, 더 이상 업데이트가 되지 않거나, 커스터마이징이 어려워 한계를 느끼는 경우가 많았습니다.

그런 와중에 검색을 통해 **TipTap Editor**를 알게 되었고, 기본적인 **텍스트 편집** 기능은 물론, 강력한 **커스터마이징과 확장성**을 통해 복잡한 에디터 기능도 구현할 수 있다는 점이 매력적으로 다가왔습니다. 이번 글에서는 TipTap Editor를 활용해 기본적인 텍스트 편집 기능과 커스터마이징 기능을 작성해 보고자 합니다.

## TipTap Editor

TipTap Editor는 ProseMirror를 기반으로 구축된 에디터로 단순한 텍스트 편집 기능뿐만 아니라, 확장성과 커스터마이징을 통해 고도의 에디터 기능을 구현할 수 있는 점이 큰 특징입니다.

기존의 에디터인 React Quill이나 React Draft가 더 이상 적극적으로 업데이트되지 않는 것과 달리, TipTap은 모던 웹 환경에 맞춰 활발히 발전하고 있습니다. React, Vue, 또는 Vanilla JavaScript와 같은 다양한 프레임워크와 호환되며, 기본적인 기능 외에도 링크, 이미지 삽입, 커스텀 요소 추가 등 고급 기능을 손쉽게 확장할 수 있습니다.

## Nextjs에서 설치하기

Nextjs에서 TipTap을 설치하려면 매우 간단합니다. 우선 Nextjs로 웹 애플리케이션 설치를 마치셨다면, 아래의 명령어를 이용하여 설치하면 초기세팅이 간단하게 마무리 됩니다.

```powershell
npm install @tiptap/react @tiptap/pm @tiptap/starter-kit
```

TipTap 에디터는 `useEditor`라는 훅을 이용하여 에디터를 초기화 하는데, 다른 라이브러리와는 다르게 `EditorContent`라는 컴포넌트에 props로 `editor`를 넣어주기만 하면 별도의 라이브러리 설치 없이 에디터의 contents를 불러올 수 있습니다.
```tsx
'use client'
import { useEditor, EditorContent } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'

const Tiptap = () => {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello World! 🌎️</p>', // 서버에서 받은 데이터를 넣을 수도 있음
  })

  return <EditorContent editor={editor} />
}

export default Tiptap
```

## 기본 사용법

위의 기본 세팅 코드에서 살펴볼 수 있듯이 `useEditor`파라미터로 다양한 옵션을 추가하여 커스터마이징 할 수 있는데 많은 다양한 옵션 중에서 가장 중요한 옵션은 다음과 같습니다.

```tsx
const editor = useEditor({
  // 사용할 extension들(ex: 제목, 색깔등) 더 다양한 확장이 많음 배열로 새롭게 추가가 가능
  extensions: [Document, Paragraph, Text],

  // 처음 사용할 콘텐츠 html코드여야 함 서버에서 불러온 값을 등록할 수도 있음
  content: '<p>Example Text</p>',

  // 초기화 후 editor에 커서를 focus
  autofocus: true,

  // 읽기전용 or 수정
  editable: true,

  // 기본 CSS 로딩을 방지합니다 (별로 중요하지 않습니다).
  injectCSS: false,
})

<EditorContent editor={editor} />
```

### 툴바를 설정하여 기본적인 에디터 만들기

React Quill이나 Draft는 기본적으로 Toolbar를 지원하지만 Tiptap은 툴바를 직접 설정해야 합니다. 처음에 세팅할 때는 불편한 점이 있겠지만 조금만 익숙해지면 **제약없이 내 맘대로 커스터마이징** 할 수 있습니다. 지금은 기본적인 툴바만 설정해보고 아래의 커스터마이징 부분에서 자세한 내용을 적어보겠습니다. 

아까 터미널에서 설치했던 기본 extension으로 `StarterKit`이 포함되어있기 때문에 아래와 같이 **Bold**와 **Italic**을 가진 툴바를 사용할 수 있습니다.

기본적으로 editor에는 `chain()`이라는 함수가 제공되며, 이는 여러 명령을 순차적으로 실행할 수 있는 체인 API입니다. `focus()`는 에디터를 활성화해 커서를 포커싱한 뒤 작업을 시작할 수 있도록 합니다. 이를 활용하면 `chain().focus().toggleBold().run()`과 같이, 에디터에 포커스를 맞춘 후 선택한 텍스트를 굵게 만드는 명령을 간단하게 실행할 수 있습니다.

다양한 extension과 사용방법은 [공식문서](https://tiptap.dev/docs/editor/extensions/nodes?filter=free)에 자세히 설명되어있기 때문에 항상 공식문서를 확인하시기 바랍니다.
```tsx
const MenuBar = ({ editor }:{ editor: Editor | null }) => {
  if (!editor) return null;

  return (
    <div>
      <button
        onClick={() => editor.chain().focus().toggleBold().run()}
        disabled={!editor.can().chain().focus().toggleBold().run()}
      >
        Bold
      </button>
      <button
        onClick={() => editor.chain().focus().toggleItalic().run()}
        disabled={!editor.can().chain().focus().toggleItalic().run()}
      >
        Italic
      </button>
    </div>
  );
};

const App = () => {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello, Toolbar!</p>',
  });

  return (
    <div>
      <MenuBar editor={editor} />
      <EditorContent editor={editor} />
    </div>
  );
};
```

## 커스터마이징 하기

TipTap에서 커스터마이징을 하는 방법은 **EditorContents**와 **Toolbar**로 나누어서 적용할 수 있습니다. 

### EditorContent

에디터 콘텐츠의 HTML들은 `.tiptap` 클래스가 있는 컨테이너 안에 렌더링됩니다 따라서 아래처럼 스타일링이 가능합니다.

#### CSS 사용

```css
.tiptap p {
  margin: 1em 0;
}
```

#### 커스텀 클래스 사용
또는 에디터 옵션에서 각 커스텀 클래스에 대한 값을 추가할 수 있습니다.

```css
.my-custom-paragraph{
  margin: 1em 0;
  color: red;
}

.my-custom-heading{
  margin: 1em 0;
  color: blue;
}
```

```tsx
// useEditor or new Editor
Editor({
  extensions: [
    Document,
    Paragraph.configure({
      HTMLAttributes: {
        class: 'my-custom-paragraph',
      },
    }),
    Heading.configure({
      HTMLAttributes: {
        class: 'my-custom-heading',
      },
    }),
    Text,
  ],
})
```

#### Tailwindcss 사용


Tailwindcss를 사용할 떄에는 editor 자체에 class를 전달하여 사용합니다.

```tsx
// useEditor or new Editor
Editor({
  editorProps: {
    attributes: {
      class: 'prose prose-sm sm:prose lg:prose-lg xl:prose-2xl mx-auto focus:outline-none',
    },
  },
})
```


### Toolbar

Toolbar를 커스터마이징 하는데는 다양한 방식이 있겠지만 저는 프로젝트에서 shadcn-ui를 사용하고 있었기 때문에 shadcn-ui의 dropdown 컴포넌트를 이용하여 toolbar를 커스터마이징 하였습니다.

아래의 코드는 드롭다운 기능을 가진 간단한 toolbar입니다. 지금은 dropdown이 Heading에만 되어잇지만 fontSize, color등 다양한 버튼을 커스터마이징 할 수 있습니다.

```tsx
import React from 'react';
import { DropdownMenu, DropdownMenuTrigger, DropdownMenuContent, DropdownMenuItem } from '@radix-ui/react-dropdown-menu';
import { Editor } from '@tiptap/react';
import { clsx } from 'clsx';

interface ToolbarProps {
  editor: Editor | null;
}

const DropdownToolbar = ({ editor }:ToolbarProps) => {
  if (!editor) return null;

  return (
    <div className="flex items-center space-x-4">
      {/* Bold Button */}
      <button
        className={clsx(
          'px-3 py-1 border rounded-md bg-white hover:bg-gray-100',
          editor.isActive('bold') && 'bg-gray-200 font-bold'
        )}
        onClick={() => editor.chain().focus().toggleBold().run()}
      >
        Bold
      </button>

      {/* Italic Button */}
      <button
        className={clsx(
          'px-3 py-1 border rounded-md bg-white hover:bg-gray-100',
          editor.isActive('italic') && 'bg-gray-200 font-bold'
        )}
        onClick={() => editor.chain().focus().toggleItalic().run()}
      >
        Italic
      </button>

      {/* Underline Button */}
      <button
        className={clsx(
          'px-3 py-1 border rounded-md bg-white hover:bg-gray-100',
          editor.isActive('underline') && 'bg-gray-200 font-bold'
        )}
        onClick={() => editor.chain().focus().toggleUnderline().run()}
      >
        Underline
      </button>

      {/* Heading Dropdown */}
      <DropdownMenu>
        <DropdownMenuTrigger className="px-3 py-1 border rounded-md bg-white hover:bg-gray-100">
          Heading
        </DropdownMenuTrigger>
        <DropdownMenuContent className="rounded-md border bg-white shadow-md">
          <DropdownMenuItem
            className={clsx('px-4 py-2', editor.isActive('heading', { level: 1 }) && 'bg-gray-200')}
            onClick={() => editor.chain().focus().toggleHeading({ level: 1 }).run()}
          >
            Heading 1
          </DropdownMenuItem>
          <DropdownMenuItem
            className={clsx('px-4 py-2', editor.isActive('heading', { level: 2 }) && 'bg-gray-200')}
            onClick={() => editor.chain().focus().toggleHeading({ level: 2 }).run()}
          >
            Heading 2
          </DropdownMenuItem>
          <DropdownMenuItem
            className={clsx('px-4 py-2', editor.isActive('heading', { level: 3 }) && 'bg-gray-200')}
            onClick={() => editor.chain().focus().toggleHeading({ level: 3 }).run()}
          >
            Heading 3
          </DropdownMenuItem>
        </DropdownMenuContent>
      </DropdownMenu>
    </div>
  );
};

export default DropdownToolbar;
```

### Extension 

![프로젝트 Horizontal](https://res.cloudinary.com/dxesudkxn/image/upload/v1735850097/blog/Nextjs%20Tiptap/wy98dcukgyxt01bf9sc7.png)

커스터마이징 중에 가장 복잡하고 어려운 부분이지만 Tiptap에서는 Extension을 커스터마이징 할 수 있습니다. 저희 프로젝트에서는 에디터에서 다양한 **horizontal rule** 필요했는데 TipTap에서는 기본형만 제공하고 점선형과 도트형은 제공하지 않아서 제가 따로 커스터마이징이 필요했습니다.

지금 예제 코드에서는 위의 사진에서 **도트형 horizontal rule** 의 예제를 사용하겠습니다. 

#### CSS 스타일링하기 

우선 가장 처음에 할 일은 **도트형 horizontal rule** 스타일링을 설정해 줍니다. 


```css
.custom-div-with-circles {
  display: flex;
  width: 100%;
  column-gap: 30px;
  justify-content: center;
  align-items: center;
  margin-top: 13px;
  margin-bottom: 13px;
}

.circle {
  width: 4px;
  height: 4px;
  border-radius: 50%;
  background-color: #717680;
}
```

#### TipTap Commands의 인터페이스 확장하기

우리가 만들려고 하는 Rule 처음부터 새로 만들어지기 때문에 지금 설정한 도트형 horizontal rule을 바로 사용하려면 Type에러가 발생하게 됩니다. 따라서 TipTap Commands의 인터페이스를 확장해서 타입 오류를 없애야 합니다.

```tsx
declare module '@tiptap/core' {
  interface Commands<ReturnType> {
    customDivWithCircles: {
      /**
       * 다양한 스타일을 가진 Horizontal Rule을 삽입합니다.
       */
      insertCustomDivWithCircles: () => ReturnType;
    };
  }
}
```

#### 노드 만들기

다음으로 새로만들 노드를 설정하고 옵션들을 추가해 줍니다. 기본적인 옵션은 주석으로 처리하였고 중요한 내용만을 설명하겠습니다.


    **parseHTML**
    parseHTML 메서드는 HTML에서 특정 태그(예: `<div class="custom-div-with-circles">`)를 인식하고, 이를 에디터의 **문서 모델Document Model**에 매핑합니다.

    **renderHTML()**
    renderHTML 메서드는 문서 모델의 노드를 HTML로 렌더링합니다. 아래의 코드에서는 `div`와 내부에 `circle` 클래스를 가진 3개의 자식 요소를 렌더링합니다.

    **addCommands()**
    addCommands 메서드는 커스텀 명령어를 정의합니다. insertCustomDivWithCircles라는 명령어를 추가해, 에디터에 새로운 커스텀 요소를 삽입할 수 있도록 할 수 있습니다.

    **addInputRules()**
    addInputRules 메서드는 특정 입력 패턴(예: ---, ___,또는 다른 마크다운 언어도 사용가능)을 감지하여 자동으로 노드를 삽입합니다.


```tsx
export const CustomDotsHorizontalRule = Node.create({
  name: 'customDivWithCircles', // 노드 이름
  group: 'block', // 블록 그룹에 속함
  content: 'inline*', // 인라인 콘텐츠 허용

  // HTML에서 커스텀 요소를 인식
  parseHTML() {
    return [
      {
        tag: 'div.custom-div-with-circles',
      },
    ];
  },

  // 노드가 렌더링되는 HTML 구조
  renderHTML({ HTMLAttributes }) {
    return [
      'div',
      mergeAttributes(HTMLAttributes, { class: 'custom-div-with-circles' }),
      ['div', { class: 'circle' }],
      ['div', { class: 'circle' }],
      ['div', { class: 'circle' }],
    ];
  },

  // 명령어 추가
  addCommands() {
    return {
      insertCustomDivWithCircles:
        () =>
        ({ chain }) => {
          return chain()
            .insertContent({
              type: this.name,
              content: [],
            })
            .run();
        },
    };
  },

  // 입력 패턴으로 노드 생성
  addInputRules() {
    return [
      nodeInputRule({
        find: /^(?:---|—-|___\s|\*\*\*\s)$/, // `---`, `___` 등으로 요소 생성
        type: this.type,
      }),
    ];
  },
});
```
#### 전체 코드


```tsx
import { Node, mergeAttributes, nodeInputRule } from '@tiptap/core';

// TipTap의 Commands 인터페이스 확장
declare module '@tiptap/core' {
  interface Commands<ReturnType> {
    customDivWithCircles: {
      /**
       * 다양한 스타일을 가진 Horizontal Rule을 삽입합니다.
       */
      insertCustomDivWithCircles: () => ReturnType;
    };
  }
}

export const CustomDotsHorizontalRule = Node.create({
  name: 'customDivWithCircles',

  group: 'block',

  content: 'inline*',

  parseHTML() {
    return [
      {
        tag: 'div.custom-div-with-circles',
      },
    ];
  },

  renderHTML({ HTMLAttributes }) {
    return [
      'div',
      mergeAttributes(HTMLAttributes, { class: 'custom-div-with-circles' }),
      ['div', { class: 'circle' }],
      ['div', { class: 'circle' }],
      ['div', { class: 'circle' }],
    ];
  },

  addCommands() {
    return {
      insertCustomDivWithCircles:
        () =>
        ({ chain }) => {
          return chain()
            .insertContent({
              type: this.name,
              content: [],
            })
            .run();
        },
    };
  },

  addInputRules() {
    return [
      nodeInputRule({
        find: /^(?:---|—-|___\s|\*\*\*\s)$/,
        type: this.type,
      }),
    ];
  },
});
```

#### Editor의 Extension에 추가 

이제 만들어진 extension을 에디터에 추가하면 커스텀 extension을 자유롭게 사용 가능합니다.

```tsx
const App = () => {
  const editor = useEditor({
    extensions: [StarterKit, CustomDotsHorizontalRule],
    content: '<p>Here is a custom horizontal rule:</p>',
  });

  return (
    <div>
      <EditorContent editor={editor} />
      <button
        onClick={() =>
          editor.chain().focus().insertCustomDivWithCircles().run()
        }
      >
        Add Custom Horizontal Rule
      </button>
    </div>
  );
};
```

## 마치며

TipTap은 **블록을 조립하는 레고**처럼, **에디터를 원하는 형태로 확장하고 조립할 수 있는** 유용한 라이브러리였습니다. 기본 제공 기능만으로도 충분히 강력했지만, 커스터마이징을 통해 **도트형 Horizontal Rule** 같은 고유한 요소를 구현하며 프로젝트의 요구사항을 충족할 수 있었습니다.

앞으로 진행할 다른 프로젝트에서도 에디터를 구현할 기회가 있다면 TipTap 에디터를 적극 활용해 볼 생각입니다!
