## TipTap Editor

TipTap Editor는 ProseMirror를 기반으로 구축된 에디터로 단순한 텍스트 편집 기능뿐만 아니라, 확장성과 커스터마이징을 통해 고도의 에디터 기능을 구현할 수 있는 점이 큰 특징입니다.

기존의 에디터인 React Quill이나 React Draft가 더 이상 적극적으로 업데이트되지 않는 것과 달리, TipTap은 모던 웹 환경에 맞춰 활발히 발전하고 있습니다. React, Vue, 또는 Vanilla JavaScript와 같은 다양한 프레임워크와 호환되며, 기본적인 기능 외에도 링크, 이미지 삽입, 커스텀 요소 추가 등 고급 기능을 손쉽게 확장할 수 있습니다.

## Nextjs에서 설치하기

Nextjs에서 TipTap을 설치하려면 매우 간단합니다. 우선 Nextjs로 웹 애플리케이션 설치를 마치셨다면, 아래의 명령어를 이용하여 설치하면 초기세팅이 간단하게 마무리 됩니다.

```powershell
npm install @tiptap/react @tiptap/pm @tiptap/starter-kit
```

TipTap 에디터는 `useEditor`라는 훅을 이용하여 에디터를 초기화 하는데, 다른 라이브러리와는 다르게 `EditorContent`라는 컴포넌트에 props로 `editor`를 넣어주기만 하면 별도의 라이브러리 설치 없이 에디터의 contents를 불러올 수 있습니다.
```tsx
'use client'
import { useEditor, EditorContent } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'

const Tiptap = () => {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello World! 🌎️</p>', // 서버에서 받은 데이터를 넣을 수도 있음
  })

  return <EditorContent editor={editor} />
}

export default Tiptap
```

## 기본 사용법

위의 기본 세팅 코드에서 살펴볼 수 있듯이 `useEditor`파라미터로 다양한 옵션을 추가하여 커스터마이징 할 수 있는데 많은 다양한 옵션 중에서 가장 중요한 옵션은 다음과 같습니다.

```tsx
const editor = useEditor({
  // 사용할 extension들(ex: 제목, 색깔등) 더 다양한 확장이 많음 배열로 새롭게 추가가 가능
  extensions: [Document, Paragraph, Text],

  // 처음 사용할 콘텐츠 html코드여야 함 서버에서 불러온 값을 등록할 수도 있음
  content: '<p>Example Text</p>',

  // 초기화 후 editor에 커서를 focus
  autofocus: true,

  // 읽기전용 or 수정
  editable: true,

  // 기본 CSS 로딩을 방지합니다 (별로 중요하지 않습니다).
  injectCSS: false,
})

<EditorContent editor={editor} />
```

### 툴바를 설정하여 기본적인 에디터 만들기

React Quill이나 Draft는 기본적으로 Toolbar를 지원하지만 Tiptap은 툴바를 직접 설정해야 합니다. 처음에 세팅할 때는 불편한 점이 있겠지만 조금만 익숙해지면 **제약없이 내 맘대로 커스터마이징** 할 수 있습니다. 지금은 기본적인 툴바만 설정해보고 아래의 커스터마이징 부분에서 자세한 내용을 적어보겠습니다. 

아까 터미널에서 설치했던 기본 extension으로 `StarterKit`이 포함되어있기 때문에 아래와 같이 **Bold**와 **Italic**을 가진 툴바를 사용할 수 있습니다.

기본적으로 editor에는 `chain()`이라는 함수가 제공되며, 이는 여러 명령을 순차적으로 실행할 수 있는 체인 API입니다. `focus()`는 에디터를 활성화해 커서를 포커싱한 뒤 작업을 시작할 수 있도록 합니다. 이를 활용하면 `chain().focus().toggleBold().run()`과 같이, 에디터에 포커스를 맞춘 후 선택한 텍스트를 굵게 만드는 명령을 간단하게 실행할 수 있습니다.

다양한 extension과 사용방법은 [공식문서](https://tiptap.dev/docs/editor/extensions/nodes?filter=free)에 자세히 설명되어있기 때문에 항상 공식문서를 확인하시기 바랍니다.
```tsx
const MenuBar = ({ editor }:{ editor: Editor | null }) => {
  if (!editor) return null;

  return (
    <div>
      <button
        onClick={() => editor.chain().focus().toggleBold().run()}
        disabled={!editor.can().chain().focus().toggleBold().run()}
      >
        Bold
      </button>
      <button
        onClick={() => editor.chain().focus().toggleItalic().run()}
        disabled={!editor.can().chain().focus().toggleItalic().run()}
      >
        Italic
      </button>
    </div>
  );
};

const App = () => {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello, Toolbar!</p>',
  });

  return (
    <div>
      <MenuBar editor={editor} />
      <EditorContent editor={editor} />
    </div>
  );
};
```
