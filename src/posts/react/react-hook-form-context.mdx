**React Hook Form**은 간결한 API와 뛰어난 성능 덕분에 React 환경에서 널리 사용되는 폼 라이브러리입니다. 그러나 **폼 상태를 여러 컴포넌트에서 공유**해야 할 때, 기존의 방식대로 사용한다면, **복잡해지고 유지보수가 어려**워질 수 있습니다.

이 문제를 해결하기 위해 React Hook Form은 **useFormContext**를 제공합니다. 이를 활용하면 폼 상태와 관련 메서드를 Context API로 관리하여, 컴포넌트 간 상태 공유를 간단하고 효율적으로 처리할 수 있습니다. 이번 글에서는 useFormContext를 활용해 기존 코드를 개선하고, 효율적인 폼 상태 관리 방법을 살펴보겠습니다.

## 기존 React Hook Form 구조의 문제점
기존 방식에서는 `useForm` 훅으로 폼 상태를 관리하며, 상태를 자식 컴포넌트로 전달할 때 **Props Drilling**이 발생하는 경우가 많았습니다. 다음은 기본적인 React Hook Form 코드 예제입니다.

```tsx
import React from 'react';
import { useForm, SubmitHandler } from 'react-hook-form';

interface FormValues {
  name: string;
  email: string;
}

const App = () => {
  const { register, handleSubmit } = useForm<FormValues>();

  const onSubmit: SubmitHandler<FormValues> = (data) => {
    console.log(data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      {/* 여러가지 form 컴포넌트 */}
      <input {...register('name')} placeholder="Name" />
      <input {...register('email')} placeholder="Email" />
      {/* 더 많은 컴포넌트들... */}
      <button type="submit">Submit</button>
    </form>
  );
};

export default App;
```
이 코드는 간단해 보이지만, 자식 컴포넌트가 많아질 경우 부모 컴포넌트에서 폼 상태를 전달하기 위해 props drilling이 발생해 코드가 점점 복잡해질 수 있습니다.

## useFormContext로 Props Drilling 해결하기

React Hook Form의 useFormContext는 폼 상태와 메서드를 Context API로 관리해 컴포넌트 간 상태 공유를 간단하게 만들어 줍니다.

### 부모 컴포넌트에서 FormProvider 사용

부모 컴포넌트에서 `FormProvider`를 사용해 폼 상태를 전역적으로 제공합니다.

```tsx
import React from 'react';
import { useForm, FormProvider, SubmitHandler } from 'react-hook-form';

interface FormValues {
  name: string;
  email: string;
}

const App = () => {
  const methods = useForm<FormValues>();

  const onSubmit: SubmitHandler<FormValues> = (data) => {
    console.log(data);
  };

  return (
    <FormProvider {...methods}>
      <form onSubmit={methods.handleSubmit(onSubmit)}>
        <NameField />
        <EmailField />
        {/* 더 많은 컴포넌트들... */}
        <button type="submit">Submit</button>
      </form>
    </FormProvider>
  );
};

export default App;
```

#### 자식 컴포넌트에서 useFormContext 사용

자식 컴포넌트는 ``useFormContext`를 통해 필요할 때 언제든 폼 상태와 메서드를 가져다 사용할 수 있습니다.

```tsx
import React from 'react';
import { useFormContext } from 'react-hook-form';

const NameField= () => {
  const { register } = useFormContext();
  return <input {...register('name')} placeholder="Name" />;
};

const EmailField = () => {
  const { register } = useFormContext();
  return <input {...register('email')} placeholder="Email" />;
};
```

## 실제 프로젝트에 적용

다단계 폼처럼 컴포넌트 간 상태 공유가 필요한 구조에서도 `useFormContext`는 매우 유용합니다. 아래는 단계별 폼을 간단히 구현한 예제입니다.

```tsx
import React from 'react';
import { useForm, FormProvider, useFormContext } from 'react-hook-form';

interface FormValues {
  name: string;
  email: string;
  password: string;
}

const Step1= () => {
  const { register } = useFormContext();
  return (
    <div>
      <input {...register('name')} placeholder="Name" />
      <input {...register('email')} placeholder="Email" />
    </div>
  );
};

const Step2 = () => {
  const { register } = useFormContext();
  return <input {...register('password')} placeholder="Password" />;
};

const MultiStepForm = () => {
  const methods = useForm<FormValues>();
  const [currentStep, setCurrentStep] = useState(1);

  const onSubmit = (data: FormValues) => {
    console.log(data);
  };


  return (
    <FormProvider {...methods}>
      <form onSubmit={methods.handleSubmit(onSubmit)}>
      { currentStep === 1 && <Step1 /> }
      { currentStep === 2 && <Step2 /> }

      { currentStep === 1 && <button type="submit">Submit</button> }

      {/*TODO : 클릭 시 이동시키기*/}
      { currentStep === 2 && <button type="button">Next</button> }
      </form>
    </FormProvider>
  );
};

export default MultiStepForm;
```

## 마치며
React Hook Form의 **useFormContext**를 활용하면 폼 상태 관리를 간결하고 체계적으로 구현할 수 있습니다. Context API를 통해 Props Drilling을 제거하고, 컴포넌트 간 상태 공유를 더 효율적으로 처리할 수 있었습니다.

특히, 다단계 폼처럼 구조가 복잡한 경우에도 독립적이고 일관된 코드 설계를 가능하게 하며, 유지보수성도 크게 향상됩니다. 앞으로도 폼 상태 관리가 필요한 프로젝트에서 useFormContext 패턴을 적극적으로 활용해 볼 계획입니다.
