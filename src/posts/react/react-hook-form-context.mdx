React 환경에서 **React Hook Form**은 간결한 API와 성능 최적화로 많은 개발자들이 사랑하는 form 라이브러리입니다. 기존에 사용하던 Form  그러나 폼의 상태를 여러 컴포넌트에서 공유해야 하는 경우, 단순한 상태 관리만으로는 코드가 복잡해질 수 있습니다.

이를 해결하기 위해 useContext를 사용하면, 폼 상태와 메서드를 전역적으로 관리하고 컴포넌트 간 데이터를 손쉽게 공유할 수 있습니다. 이번 글에서는 기존 React Hook Form 기반의 코드를 useContext로 개선하여 더 효율적인 상태 관리를 구현하는 방법을 살펴보겠습니다.

## 기존 React Hook Form 구조

기존에는 폼 상태를 useForm 훅으로 관리하며, 상태를 자식 컴포넌트로 전달할 때 **props drilling**이 발생하는 경우가 많았습니다. 아래의 코드는 기본적인 React Hook Form 코드 예제입니다.

```tsx
import React from 'react';
import { useForm, SubmitHandler } from 'react-hook-form';

interface FormValues {
  name: string;
  email: string;
}

const App = () => {
  const { register, handleSubmit } = useForm<FormValues>();

  const onSubmit: SubmitHandler<FormValues> = (data) => {
    console.log(data);
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      {/* 여러가지 form 컴포넌트 */}
      <input {...register('name')} placeholder="Name" />
      <input {...register('email')} placeholder="Email" />
      {/* 더 많은 컴포넌트들... */}
      <button type="submit">Submit</button>
    </form>
  );
};

export default App;
```

## useFormContext를 활용하여 Props Drilling 해결하기

React Hook Form의 **useFormContext**는 폼 상태와 메서드를 Context API로 관리하여, 컴포넌트 간 상태 공유를 간단하게 만듭니다. 

#### 부모 컴포넌트

부모 컴포넌트에서 **FormProvider**로 상태를 전역적으로 제공합니다.

```tsx
import React from 'react';
import { useForm, FormProvider, SubmitHandler } from 'react-hook-form';

interface FormValues {
  name: string;
  email: string;
}

const App = () => {
  const methods = useForm<FormValues>();

  const onSubmit: SubmitHandler<FormValues> = (data) => {
    console.log(data);
  };

  return (
    <FormProvider {...methods}>
      <form onSubmit={methods.handleSubmit(onSubmit)}>
        <NameField />
        <EmailField />
        {/* 더 많은 컴포넌트들... */}
        <button type="submit">Submit</button>
      </form>
    </FormProvider>
  );
};

export default App;
```

#### 자식 컴포넌트

자식 컴포넌트에서는 useFormContext로 필요할 때 언제든지 가져다 쓸 수 있습니다.

```tsx
import React from 'react';
import { useFormContext } from 'react-hook-form';

const NameField= () => {
  const { register } = useFormContext();
  return <input {...register('name')} placeholder="Name" />;
};

const EmailField = () => {
  const { register } = useFormContext();
  return <input {...register('email')} placeholder="Email" />;
};
```

## 실제 프로젝트에 적용

실제 프로젝트에서 저는 1단계 2단계 3단계로 넘어가는 다단계 폼을 구현해야 했는데, 나뉜 컴포넌트에서 모두 상태를 공유하기 때문에 별도의 상태 전달 없이도 데이터를 관리할 수 있습니다.

아래는 간단한 코드로 단계별 form 컴포넌트를 나타냅니다.

```tsx
import React from 'react';
import { useForm, FormProvider, useFormContext } from 'react-hook-form';

interface FormValues {
  name: string;
  email: string;
  password: string;
}

const Step1= () => {
  const { register } = useFormContext();
  return (
    <div>
      <input {...register('name')} placeholder="Name" />
      <input {...register('email')} placeholder="Email" />
    </div>
  );
};

const Step2 = () => {
  const { register } = useFormContext();
  return <input {...register('password')} placeholder="Password" />;
};

const MultiStepForm = () => {
  const methods = useForm<FormValues>();
  const [currentStep, setCurrentStep] = useState(1);

  const onSubmit = (data: FormValues) => {
    console.log(data);
  };


  return (
    <FormProvider {...methods}>
      <form onSubmit={methods.handleSubmit(onSubmit)}>
      { currentStep === 1 && <Step1 /> }
      { currentStep === 2 && <Step2 /> }

      { currentStep === 1 && <button type="submit">Submit</button> }

      {/*TODO : 클릭 시 이동시키기*/}
      { currentStep === 2 && <button type="button">Next</button> }
      </form>
    </FormProvider>
  );
};

export default MultiStepForm;
```

## 마치며

React Hook Form의 **useFormContext**를 사용하며, 폼 상태 관리가 훨씬 간결하고 체계적으로 변한다는 것을 느꼈습니다. **Context API**를 활용해 **Props Drilling**을 제거함으로써, 컴포넌트 간 상태 공유가 필요한 복잡한 폼 구조에서 독립적이고 일관된 코드 설계를 가능하게 해주었고, 다단계 폼과 같이 복잡한 구조에서도 효과적으로 작동한다는 점이 인상적이었습니다. 앞으로도 폼 상태를 관리할 때 useFormContext 패턴을 적극적으로 활용할 계획입니다.
